# 화면 목록

> 기준: PRD v2.3, 정책 명세서 v0.1
> 상태: 초안. 사이트맵·사용자 흐름 문서 작성 시 이 문서를 확장한다.

## 용병

1. 온보딩 (최초 로그인 시 선수 카드 기본 정보 입력)
2. 홈 — 경기 목록 + 필터 (지역·날짜·급수)
3. 리그별 탐색 (지역 → 리그 → 경기 일정)
4. 경기 상세 (포지션별 확정 / 입금대기 / 빈자리) — 참가자 명단 공개는 P1
5. 예약 화면 (포지션 1개 선택 + 입금자명 입력)
6. 계좌 안내 & 입금 완료 신고 화면
7. 내 예약 목록 (상태별) + 예약 취소
8. 경기 후 평가 화면 (+ 베스트플레이어 투표)
9. 선수 카드 (내 프로필 / 다른 선수 카드)
10. 신고 · 이의제기

## 주최자

1. 경기 개설 폼 (리그 → 구장 선택, 포지션별 정원, 허용 급수, 계좌)
2. 구장 등록 요청
3. 내 경기 목록
4. 경기별 대시보드 (신청자 상태 관리: RESERVED / PAYMENT_SUBMITTED / APPROVED)
5. 승인 / 거절 액션
6. 경기 취소 (사유 선택)
7. 경기 후 ATTENDED / NO_SHOW 처리

## 관리자

1. 신고 목록 · 처리
2. 노쇼·평가 이의제기 처리
3. 노쇼 2회 도달 계정 검토 → 정지 결정
4. 계정 정지 / 해제
5. 구장 등록 요청 승인
6. 리그·구장 관리
7. 주최자 역할 신청 승인 (정책 명세서 2.2 확정 시)

## 공통

- 카카오 소셜 로그인
- 선수 카드 편집

## 설계 우선순위

주최자 대시보드 우선 — 밴드 대비 차별화 포인트.
